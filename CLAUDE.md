# paleta-musical

Paleta Musical: a music-theory web app to hear and explore notes, scales, chords and
progressions. Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, pnpm.
The UI is in European Portuguese (default) and English. The repo docs are in English.
Read `AGENTS.md` (Next.js 16 differs from older versions) and `.icm/project-rules.md`.
